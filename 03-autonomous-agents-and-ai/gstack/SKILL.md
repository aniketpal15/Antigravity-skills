# GStack — Rapid Founder MVP Execution Stack

`gstack` embodies Y Combinator CEO Garry Tan's high-velocity development philosophy. Designed for solo founders and small engineering teams, it cuts through over-engineering and boilerplate to deliver production-ready software in hours.

---

## ⚡ The GStack Principles

1. **Default to the Golden Path**: Next.js App Router + Tailwind CSS + Shadcn UI + Supabase / PostgreSQL + Stripe + Vercel.
2. **Zero Vanity Architecture**: No premature microservices, no speculative abstractions, no Kubernetes clusters for early MVPs.
3. **Authentication & Billing on Day 1**: Integrate working auth and payments before building deeper features so the product is monetize-ready immediately.
4. **Deploy from Commit 1**: Set up production preview URLs from the very first commit.

---

## 🛠️ Usage
- `"gstack: scaffold a B2B SaaS boilerplate with Stripe billing"`
- `"gstack: audit this project for over-engineering and trim to MVP"`
- `"gstack: build landing page with waitlist database in 30 minutes"`
